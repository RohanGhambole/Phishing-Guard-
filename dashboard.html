How the pipeline works
01 / Ingest
ct_watcher.py
Pulls live malicious URLs from URLhaus & threat feeds. Saves to suspects.jsonl.
02 / Crawl
screenshot.py
Visits each URL with headless Chrome. Screenshots, checks for login forms and redirects.
03 / Score
scorer.py
Fuses URL features, visual similarity to real brands, Cloudflare block status into a 0–100 risk score.
04 / Takedown
sender.py
Looks up abuse contact via RDAP, emails takedown notice with screenshot evidence attached.
